# Project Afia

Project Afia is an AI-assisted family communication app designed to help elderly users stay connected with family members through natural-language and voice interactions.

## Tech Stack

- Python 3.12
- FastAPI
- PostgreSQL
- Supabase
- SQLAlchemy
- OpenAI API

## Development Progress

### Week 1: Research and Project Planning
- Met with capstone advisor to discuss project goals and expectations.
- Reviewed capstone requirements.
- Researched AI tools, retrieval-augmented generation (RAG), and agentic frameworks.
- Studied LLMs, memory management, and tool calling.
- Evaluated project feasibility and identified core features.

### Week 2: Backend Setup and Development
- Researched AI agent architecture and explored interactive GitHub examples.

- Implemented and debugged backend functionality.

### Week 3: Database Design and AI Integration
